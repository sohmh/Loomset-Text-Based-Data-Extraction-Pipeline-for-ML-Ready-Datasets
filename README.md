# Loomset : A Text Based Data Extraction Pipeline for ML Ready Datasets
An open source research project developing an end to end pipeline for automated web data extraction, preprocessing, labeling, and dataset generation to create ML ready datasets for niche domains with limited publicly available training data.
Text-Based Data Extraction Pipeline for ML-Ready Datasets is an open-source research project that investigates how web scraping, data preprocessing, automatic labeling, and scalable data engineering can be combined into a single end-to-end pipeline. The goal is to reduce the time and effort required to build high-quality machine learning datasets for niche domains where publicly available datasets are scarce or non-existent. Alongside the research, this repository documents the complete development of a working prototype, experimental evaluations, and the research paper.
