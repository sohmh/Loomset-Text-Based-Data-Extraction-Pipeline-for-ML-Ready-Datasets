# Ideal Process of Project Based Learning
## The Central Idea
**The entire point of project based learning is to develop critical thinking skills while making the project. While building the project, I should try to research & do things on my own as much as possible, this type of rigorous work and time is required for 'learning'. If I use LLMs to do everything, there is no hardships and there is no struggling , hence there is no point because there will be no learning.**

## The Problem I'll Face
- **P1 : I don't have that kind of experience to be implementing what I am proposing all by myself. I cannot write all that code by myself right now, but I also cannot vibecode first and then understand and call it a day because that also isn't concrete learning**
- **P2 : Even if I do make everything myself, what is the proof that I made it all by myself?**

## The Solutions I came up with
- **A1 : Follow articles, research papers & books that have 'Implement X' in them and follow through the paper to code the part. Don't directly ask LLMs to give you a solution, instead ask the LLM to give you resources you can read & follow instead. Use instructions & skills in your LLM that follow the socratic approach, which doesn't directly give you answers but instead asks you questions that make you think**
- **A2 : Keep a Documentation folder, track all the problems you're facing, what you're asking the LLM to do, what resources you're referring to, sort of like a blog.**

What sort of resources am I going to need to study & implement things : I must find articles, research papers,  books that answer the following questions:  
- How to implement a web-scraper ? OR How to use a pre-existing web-scraper?
- How to implement an automated data cleaner ?
- How to implement an automated data-labeller ?
- How to connect all the pipelines together ?
